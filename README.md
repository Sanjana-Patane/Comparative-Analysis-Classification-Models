
# Comparative Analysis of Classification Models

## Aim
To implement and compare four classification algorithms using Python.

## Algorithms Used
1. Support Vector Machine (SVM)
2. Decision Tree
3. K-Nearest Neighbors (KNN)
4. Gaussian Naive Bayes

## Dataset
A synthetic binary classification dataset containing 1000 samples and 10 features is generated using Scikit-learn.

## Tools and Libraries
- Python
- NumPy
- Pandas
- Scikit-learn

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Log Loss

## How to Run the Project
1. Install Python.
2. Open a terminal in the project folder.
3. Install the required libraries:

   pip install -r requirements.txt

4. Run the Python program:

   python classification_models.py

5. Observe the comparison table displayed in the terminal.

## Conclusion
This project compares four classification algorithms using common evaluation metrics. The results help us understand how different algorithms perform on the same dataset.
